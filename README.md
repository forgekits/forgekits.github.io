# forgekits.github.io

Source of <https://forgekits.github.io>, the site of forgekits: production kits for AI agents on the Claude Agent SDK.

Plain HTML and CSS, no build step, no JavaScript, no third-party requests, no cookies. GitHub Pages serves the `main` branch as is (`.nojekyll` disables the Jekyll build).

- `index.html`: the whole site.
- `404.html`: served for unknown paths.
- `favicon.svg`: the monogram.

Content changes are edits to `index.html`. Keep every claim on the page backed by a test or a document in the kits.
