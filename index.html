Why the SDK alone is not enough

The Claude Agent SDK gives you maxBudgetUsd and maxTurns, and they work. They are per query. Three things are missing once an agent runs unattended.

Nothing spans runs

A hundred queries can each spend their cap. Daily, monthly and per-customer budgets have to be yours, and two concurrent runs must not overshoot together.

Nothing remembers failures

If the API has been failing for ten minutes, the next run tries anyway. A circuit breaker that survives a restart stops the bleeding.

Nothing records decisions

Which tool was called, with which arguments, on behalf of which customer, and whether it was allowed. A policy with an audit log answers that.

Start with the Lite kit

What you would write in the first two days anyway, already written and tested. About 750 lines of commented code. Clone it, read it, delete what you do not need.

What is in the box

  • Config: environment variables validated with a schema, every problem listed at once, a tiny .env loader.
  • Tools: calculate (a safe parser, no eval), save_note and search_notes, plus your own via extraTools.
  • Agent: a locked-down run wrapper. No built-in tools, no host settings, pre-approved tools only, turn and budget limits, an audit hook.
  • Report: a flat summary with cost, tokens and per-model usage, and one sentence that explains a failure. An invalid API key is reported as a failure, not as success.
  • CLI, tests and CI: answer on stdout, report on stderr; unit tests that never call the API; GitHub Actions on Linux and Windows.

Requirements: Node.js 20 or later, or Python 3.10 or later, and an Anthropic API key.

TypeScript

git clone https://github.com/forgekits/agent-sdk-kit-lite my-agent && cd my-agent
npm ci
npm run check           # typecheck + 46 unit tests, no API key needed
cp .env.example .env    # ANTHROPIC_API_KEY=sk-ant-...
npm run agent -- "What is (1200 * 1.081) / 12? Then remember that my rent is 1200."

Questions

Is this a framework?

No. Both kits are ordinary functions in a repository you own. There is no runtime, no plugin system and no abstraction over the SDK. If you want to change how a budget is reserved, you edit budget.ts.

Do I need an Anthropic API key?

Yes. The kits refuse to start without ANTHROPIC_API_KEY. Without that guard the SDK would fall back to a Claude Code login on the host, which Anthropic does not permit for third-party products.

How are the claims on this page verified?

Every feature named here is covered by a unit test that runs in CI without an API key: 46 tests in the TypeScript Lite kit, 50 in the Python Lite kit, 107 in Pro. The Lite test suites are public; run npm run check or pytest -q after cloning.

What does the Pro license allow?

Use in any number of your own products, commercial or not, by the licensed people (one for Solo, up to five for Team). You may not resell or redistribute the kit itself. Updates are included for 12 months after purchase; the kit keeps working after that.

Is there a Python version of Pro?

Not yet. The Python Lite kit is free today and mirrors the TypeScript one. A Python Pro kit is planned; buyers of Pro will hear about it first.

How do I report a security issue?

Open a private security advisory on the Lite repository, also for the Pro kit. Please do not open a public issue for a vulnerability. You will get an acknowledgement within 72 hours.
